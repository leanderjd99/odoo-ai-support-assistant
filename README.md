# Odoo AI Support Assistant

An open-source project exploring AI-assisted helpdesk workflows for small businesses using Python and Odoo.

## Current Features

- Classifies helpdesk tickets as confirmed, cancelled, or question.
- Generates suggested support replies.
- Runs locally using Python without paid API access.

## Technology

- Python
- Git and GitHub
- Planned: Odoo integration and Claude API support

## Project Status

Early development. The current classifier uses simple rules, not an AI model.

## Run Locally

Activate your virtual environment and run:

    python app.py
