# Odoo AI Support Assistant

An open-source project exploring AI-assisted helpdesk workflows for small businesses using Python and Odoo.

## Goals

- Classify helpdesk tickets by type and urgency.
- Summarize customer conversations.
- Suggest support replies for human review.
- Explore integration with Odoo Helpdesk.
- Provide a simple, documented setup for developers.

## Planned technology

- Python
- Odoo integration
- FastAPI for an optional standalone API
- Large language model integration

## Project status

Early development. Features will be implemented and documented incrementally.
